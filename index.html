2. The model — a real trained GCN

This isn't random weights. It's a 2-layer graph convolutional network, trained (via hand-written numpy forward/backward passes — no PyTorch needed for this small a model) on Zachary's Karate Club: a real social network of 34 club members, famous in graph theory because the club actually split into two factions. Shown the true faction for just 2 of the 34 members, the model predicts all 34 correctly 97.1% of the time — learning purely from the graph structure. Exported to ONNX (the format torch.onnx.export() produces from a real PyTorch model), so this is a faithful test of the actual deployment pipeline.

3. Scalability stress test

The trained model above only has 34 nodes to work with — too small to show a real CPU/GPU gap. This section runs the same two-layer GCN architecture (same math, freshly randomized larger graphs) at sizes you control, purely to compare raw compute speed.
